HW1. Лексер: регулярное выражение → ДКА → минимизация
Цели
Превратить набор регулярных выражений в ДКА и минимизировать его.
Подготовить таблицу переходов для будущего лексера проекта.
Собрать тесты на краевые случаи токенов.
Задание
Принять список регулярных выражений для токенов языка Funny (IDENT, INT, WS, COMMENT, OP/делимитеры/ключевые слова function/returns/...).
Построить НКА (Томпсон) → ДКА (subset construction) → минимизированный ДКА (Хопкрофт).
Сгенерировать таблицу переходов (формат на выбор: JSON/CSV/код).
Добавить «ловушку» для непокрытых символов.
Подготовить набор положительных и отрицательных тестов.
Требования к реализации
Язык реализации - любой, но воспроизводимый из CLI.
Поддержка позиций не обязательна (будет в HW2).
WS/COMMENT можно пометить как «skip», остальные токены — принимающие.
Алфавит входа: ASCII (фиксирован в спецификации языка); важно покрытие всех символов в тестах.
Вход/выход (минимальный сценарий)
Вход: файл с регулярными выражениями или вшитый список.
Выход: сериализованный ДКА (переходы, стартовое состояние, принимающие), список тестов и их статусы.
Тестирование
Обязательные сценарии: пустая строка; строки только из пробелов/табов/CRLF; 0, 00, 01 (отрицательный пример); идентификаторы с _; ключевые слова (function, returns, while, if, else, assert, assume, invariant, length); границы/операторы ()[]{},; + - * / == != <= >= < > =; комментарии //... до конца строки; выход за алфавит (non-ASCII) должен попадать в ловушку.
Проверка: прогон тестовых строк через построенный ДКА, сравнение ожидаемых токенов/ошибок.
Формат сдачи
Код + README с инструкцией запуска.
Отчёт (кратко): список регулярных выражений, размер ДКА до/после минимизации, ловушка.
Тесты: входные строки + ожидаемый результат.
Дополнительно: экспорт таблицы переходов/автомата так, чтобы её можно было подключить в лексер проекта (T0).
Критерии оценки (10 баллов)
Корректное построение и минимизация ДКА — 4 балла
Покрытие тестами, граничные случаи — 2 балла
Формат вывода/таблиц и воспроизводимость — 2 балла
Отчетность и структура — 2 балла
