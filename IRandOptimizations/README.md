# HW04. Промежуточное представление и оптимизации

## Запуск

Нужны JDK 25 и Maven. Из `IRandOptimizations` выполните:

```sh
mvn test
java -cp target/classes ru.nsu.naboka.ir.Main examples/arithmetic.funny
java -cp target/classes ru.nsu.naboka.ir.Main --no-opt examples/control.funny
```

Исходники HW1 и HW3 подключаются из соседних каталогов `regex_dfa` и `parser`. Без имени файла CLI читает Funny из стандартного ввода. В stdout выводятся IR до и после, CFG, граф конфликтов с цветами и метрики по функциям. CFG и граф конфликтов относятся к IR после оптимизаций.

Все оптимизации включены по умолчанию. `--no-const` отключает распространение и свёртку констант, `--no-algebra` отключает алгебраические упрощения, `--no-dce` отключает удаление мёртвого кода. `--no-opt` отключает все три прохода.

## Формат IR

`fun имя($параметр:тип, …) -> (типы результатов)` задаёт сигнатуру. `$имя` обозначает переменную, `%tN` — временную, `L0:` — метку блока. Метки и временные нумеруются отдельно в каждой функции. Операндом может быть переменная, временная либо константа `int`, `bool` или `null` типа `int[]`.

| Запись | Назначение |
| --- | --- |
| `цель:тип = op аргументы` | `copy`, `neg`, `not`, `add`, `sub`, `mul`, `div`, `eq`, `ne`, `lt`, `le`, `gt`, `ge`, `length`, `get`, `set` |
| `цели = call имя(аргументы)` | Сначала читаются аргументы, затем записываются результаты в порядке сигнатуры |
| `branch условие, L1, L2` | Переход на первую метку при `true` и на вторую при `false` |
| `jump L1` | Безусловный переход |
| `return значения` | Возврат одного или нескольких значений в порядке сигнатуры |

Функция начинается с первой метки. Блок без перехода или возврата передаёт управление следующему блоку. `and`, `or` и `->` вычисляются с коротким замыканием. `set` возвращает копию массива с изменённым элементом. `eq` и `ne` сравнивают массивы по содержимому.

`int` соответствует 32-битному `int` JVM, включая переполнение. Начальные значения локальных переменных и именованных результатов — `0`, `false` или `null` по типу. `requires`, `ensures`, `invariant`, `assert` и `assume` остаются аннотациями верификации. Формулы, вызванные из исполняемых выражений, генерируются как функции с результатом `bool`. Кванторы поддерживаются в части верификации.

## API для кодогенерации

```java
var functions = IrGenerator.generate(checked);
var optimized = Optimizer.optimize(functions.getFirst(), new Optimizer.Options(true, true, true));
var blocks = ControlFlow.build(optimized);
var allocation = RegisterAllocation.allocate(blocks);
```

`checked` — успешный `SemanticAnalyzer.Result` из HW3 после проверки ошибок парсера. `Ir.Function` хранит типы параметров и результатов и список типизированных инструкций. `ControlFlow.Block` хранит метку, инструкции и метки преемников. `allocation.colors()` сопоставляет временным номера с нуля. При генерации JVM-кода именованным значениям можно выделить отдельные локальные слоты, а цвет использовать как смещение в области слотов для временных. Для вызовов и возврата с несколькими результатами бэкенд должен использовать одну схему упаковки в порядке сигнатуры.

## Краткий отчёт

- Распространение заменяет чтение известной константой внутри блока. Свёртка вычисляет операции с константными аргументами.
- Алгебраические упрощения применяют правила вроде `x + 0 → x`, `x * 1 → x` и `x * 0 → 0`.
- Локальный DCE идёт по блоку в обратном порядке с учётом живости на выходе. Он сохраняет вызовы и операции, которые могут завершиться исключением.
- Живость вычисляется до неподвижной точки по CFG. Временная конфликтует с другими временными, живыми сразу после её записи. Жадная раскраска выбирает наименьший свободный цвет.

| Функция | Инструкции | Временные | Цвета |
| --- | ---: | ---: | ---: |
| `calc` | 18 → 7 | 11 → 5 | 3 → 2 |
| `pair` | 7 → 5 | 2 → 2 | 1 → 1 |
| `compute` | 27 → 23 | 9 → 9 | 1 → 1 |

Метки в число инструкций не входят. Тесты выполняют IR до и после на одинаковых входах и проверяют результаты арифметики, ветвлений, циклов и вызовов. Они также проверяют сохранение исключений и конфликты между блоками.

- Ветвления, цикл и вызов с двумя результатами. [Вход](examples/control.funny), [вывод](examples/control.out)
